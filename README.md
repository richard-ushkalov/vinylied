# Vinilyed

Музыкальный плеер-полка: ваши треки стоят на 3D-полке, как виниловые
пластинки. Пластинка разгоняется и тормозит вместе со звуком, при
прокрутке звук глохнет, как на пульте, а обложки и названия
подтягиваются из интернета.

Это установленное приложение (PWA) для Android, iPhone и компьютера:
музыка сохраняется внутри приложения и играет без интернета.

## Как пользоваться

1. Откройте сайт в Chrome (Android, компьютер) или Safari (iPhone).
2. Установите приложение:
   - **Android:** меню «⋯» → «Установить на телефон» (или «Добавить на главный экран» в меню Chrome);
   - **iPhone:** «Поделиться» → «На экран “Домой”». Музыку добавляйте уже
     в установленном приложении: у него своё хранилище, и iOS не сотрёт его через неделю.
3. «+ Добавить музыку» — файлы копируются в приложение. Полка запоминается,
   после перезапуска ничего выбирать заново не нужно.
4. На Android музыку можно прислать из Telegram, WhatsApp и «Файлов»:
   «Поделиться» → Vinilyed.

Управление: тап по пластинке или ⏯ — играть/пауза; полоса внизу —
перемотка (можно тянуть пальцем, над ним видно время); мини-обложка в углу
возвращает к играющей пластинке. В меню «⋯» — порядок и повтор, проверка
обложек, список треков, «Удалить дубликаты», настройки. Системные кнопки (шторка Android,
экран блокировки и Пункт управления iPhone, Now Playing на Маке,
медиаклавиши) тоже работают.

### Клавиши

| Клавиша | Действие |
|---|---|
| Пробел, K | играть / пауза |
| ← → | перемотка на 5 с (с Shift — 30 с) |
| ↑ ↓, Home, End | выбор пластинки |
| Enter | играть выбранную |
| N / P | следующий / предыдущий |
| S | перемешать |
| R | повтор: полки → трека → выкл. |
| M | без звука |
| / | поиск |
| ? | справка |

### iPhone и режимы звука

На iOS звук через Web Audio (на нём построены эффекты винила)
останавливается при блокировке экрана. Поэтому режим «Авто» на iPhone —
«Надёжный»: трек играет обычным `<audio>`, в фоне и на экране блокировки.
Разгон и торможение пластинки остаются, приглушения при прокрутке и треска
нет. В настройках можно включить «Винил» со всеми эффектами, но тогда
музыка играет только при включённом экране.

### Дубликаты

«⋯» → «Удалить дубликаты» находит повторы двух видов: та же песня другим
файлом (название и исполнитель совпадают, длительность — с точностью до
пары секунд) и тот же файл под другим именем (сверяется содержимое).
Перед удалением приложение показывает, что уйдёт. Остаётся лучший
экземпляр: играющий, потом опознанный по сети, потом лучшего качества.

### Скачать из сети

Если в поиске по полке ничего не нашлось, приложение предлагает скачать
трек со своего сервера — Мака владельца со [spotDL](server/README.md).
Конверт сразу встаёт на полку прозрачным и проявляется по мере загрузки;
скачанный трек, как и любой другой, потом доводит поиск обложек и названий.

Скачивание — только для своих: нужен код доступа от владельца сервера
(«Настройки» → «Скачивание»). Без кода этой части приложения не видно.
Как поднять сервер на Маке — в [server/README.md](server/README.md).

## Обложки и названия

Проверяются все треки, в том числе со своей обложкой. Если трек узнан,
на конверте появляются правильные название, исполнитель, альбом и обложка.

1. **AcoustID** — распознавание по звуку, как Shazam. Нужен бесплатный
   ключ (только для некоммерческого использования):
   - войти на [acoustid.org](https://acoustid.org/login) через аккаунт MusicBrainz;
   - [создать приложение](https://acoustid.org/new-application) — нужен ключ именно
     приложения, личный ключ со страницы «API key» не подойдёт;
   - вписать ключ в `src/config.js` (`ACOUSTID_KEY`) или прямо в приложении:
     «Настройки → Интернет → Ключ AcoustID» (важнее встроенного).

   Состояние ключа видно там же и в меню «⋯»: не задан, проверится при
   первом поиске, работает или не принят. Без ключа этот шаг пропускается.
2. **iTunes Search** — по тегам, затем по имени файла. Ответ обязательно
   сверяется: iTunes возвращает «что-нибудь» на любой запрос.

Найденное сохраняется в приложении и показывается без интернета. Поиск
можно выключить в настройках: наружу уходят отпечаток звука и названия,
сама музыка — никогда.

## Разработка

Приложение — статика на нативных ES-модулях, без сборки. Нужен Node 22.

```sh
npm install
npm run serve        # http://127.0.0.1:4173
npm run check        # eslint + проверка типов (JSDoc) + unit-тесты
npm run test:e2e     # Playwright: телефон и десктоп
python3 -m unittest discover -s server/tests -t server   # сервер скачивания
```

После изменения списка файлов — `npm run precache`: он обновляет список
в `sw.js`, который нужен для офлайна (unit-тест проверяет, что там ничего
не пропущено). Сторонний код лежит в `vendor/` и пересобирается
`npm run vendor`, иконки — `npm run icons`.

### Публикация

`.github/workflows/pages.yml` выкладывает сайт на GitHub Pages после
зелёных проверок в `main`. Один раз в настройках репозитория:
**Settings → Pages → Source: GitHub Actions**. Для установки на телефон
нужен HTTPS — Pages его даёт.

### Устройство

```
src/
  main.js          точка сборки: создаёт объекты и связывает события
  core/            Emitter, Settings (схема настроек), FrameLoop, форматтеры
  audio/           Player (фасад) → BufferEngine («Винил») | ElementEngine («Надёжный»)
                   routes/: CarrierRoute (Chromium), StreamRoute (Safari/Firefox)
  library/         IndexedDB, Library (импорт, дубли), Track, Inbox («Поделиться»)
  media/           теги, обложки, цвет корешка
  lookup/          AcoustID + Chromaprint, iTunes, Cover Art Archive, очередь проверки
  downloads/       клиент сервера скачивания, очередь загрузок, заготовка конверта
  playback/        PlaybackController, Queue (перемешивание, повтор), Media Session
  ui/              полка, панель, прогресс, листы, темы, клавиши
styles/            токены тем и стили по компонентам
sw.js              офлайн и приём «Поделиться»
server/            сервер скачивания для Мака (Python + spotDL), на сайт не выкладывается
```

Главные правила:

- DOM ищется только в `main.js`, классы получают всё в конструкторе.
- Состоянием воспроизведения владеет `PlaybackController`; интерфейс,
  клавиши и системная панель только просят и рисуют.
- Все цвета — токены в `styles/tokens.css`, поэтому светлая тема подменяет интерфейс целиком.
- Комментарии объясняют, **почему** сделано именно так: многие решения
  обходят конкретные баги браузеров.
